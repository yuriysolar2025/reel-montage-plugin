# reel-montage — Claude сам монтирует твои ролики

Плагин для Claude Code. Кидаешь в папку свои видео, фото и голосовое («что было сегодня»). Claude:

- расшифровывает речь;
- просматривает кадры;
- пишет сценарий и текст за кадром;
- подбирает кадр под каждую фразу и собирает вертикальный ролик 1080×1920 с субтитрами, озвучкой и музыкой.

Пока идёт сборка, в браузере открыт редактор [FableCut](https://github.com/ronak-create/FableCut): видно, как на таймлайн ложатся отрезки, субтитры и звук.

Готовый ролик остаётся у тебя файлом в `out/`. Плагин ничего никуда не публикует.

## Что поставить один раз

| Что | Зачем | Mac | Windows |
|---|---|---|---|
| [Claude Code](https://claude.com/claude-code) | сам Claude | `curl -fsSL https://claude.ai/install.sh \| bash` | см. сайт |
| ffmpeg | сборка видео | `brew install ffmpeg` | `winget install ffmpeg` |
| Node.js 18+ | редактор FableCut | `brew install node` | [nodejs.org](https://nodejs.org) |
| whisper.cpp | расшифровка речи | `brew install whisper-cpp` | [сборка](https://github.com/ggml-org/whisper.cpp) |
| Python 3 + Pillow | картинки субтитров | `brew install python uv` | [python.org](https://python.org), затем `pip install pillow` |

Нет Homebrew на Маке? Поставь: [brew.sh](https://brew.sh).

Модель распознавания речи (~470 МБ) скачается сама при первой расшифровке в `~/.cache/reel-montage/`.

**Озвучка.** Можно записать текст своим голосом. А можно, чтобы Claude озвучивал клоном твоего голоса в [ElevenLabs](https://elevenlabs.io) (платный тариф с клонированием). Для этого перед запуском `claude` задай две переменные:

```bash
export ELEVENLABS_API_KEY=твой_ключ
export ELEVENLABS_VOICE_ID=id_твоего_голоса
```

Ключ никому не показывай и в папку с роликами не клади.

## Установка плагина

В Claude Code (в любой папке) выполни две команды.

Если плагин лежит у тебя папкой (например, прислали архивом):

```
/plugin marketplace add /путь/к/reel-montage-plugin
/plugin install reel-montage@reel-montage
```

Если он выложен на GitHub:

```
/plugin marketplace add <владелец>/<репозиторий>
/plugin install reel-montage@reel-montage
```

Перезапусти Claude Code. Проверка: `/plugin` покажет `reel-montage`, а `/mcp` — сервер `fablecut`.

## Первый запуск

1. Создай папку под ролики, например `~/Reels`, и положи туда:
   - `raw/` — видео и фото за день;
   - голосовое (`raw/voice.ogg`, `.m4a` или `.mp3`), где рассказываешь, что было;
   - `music/` — трек для фона (необязательно).
2. Открой Claude Code в этой папке: `cd ~/Reels && claude`.
3. Напиши: **«смонтируй день»** (или «вот голосовое и видео, собери рилс»).

Сначала Claude проверит, всё ли установлено, и скажет, чего не хватает. Потом расшифрует голосовое, просмотрит кадры, покажет сценарий и текст и соберёт ролик.

Монтаж видно вживую: редактор FableCut сам откроется в браузере (на Mac — вкладкой в Google Chrome) по адресу http://localhost:7777. Готовый файл появится в `out/`.

Править можно словами: «первый кадр замени на тот, где море», «субтитры короче», «музыку тише».

## Что внутри

- `skills/reel-montage/SKILL.md` — порядок работы для Claude: сырьё → распознавание → сценарий → озвучка → сборка → проверка.
- `skills/reel-montage/scripts/`:
  - `build_reel.py` — сборка ролика по описанию `reel.json` и живой показ в FableCut;
  - `transcribe.sh` — расшифровка речи с таймингом каждого слова;
  - `check_reel.py` — проверка формата, звука и зависаний плюс лист кадров;
  - `voice_pauses.py` — паузы в озвучке под красивые кадры;
  - `tts_elevenlabs.py` — озвучка клоном голоса (необязательно);
  - `fablecut_open.py` — запускает FableCut и открывает его в браузере (вызывается сам);
  - `doctor.sh` — проверка окружения.
- `.mcp.json` подключает FableCut (`npx fablecut@1.18.0 mcp`). Редактор работает только на твоём компьютере (127.0.0.1), его проекты лежат в `~/FableCut`.

## Если что-то не так

- **FableCut не открылся:** проверь, что стоит Node.js 18+ (`node -v`), и запусти редактор сам командой `npx -y fablecut@1.18.0`. Сборка и без него работает, просто без живого показа.
- **Порт 7777 занят:** перед запуском `claude` выполни `export FABLECUT_PORT=7788`.
- **Субтитры квадратиками:** нет шрифта с кириллицей. Скажи Claude путь к любому жирному `.ttf`, и он пропишет его в `reel.json` (`"font": "…"`).
